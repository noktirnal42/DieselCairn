## RE300, PC305, and front-engine model codes

`RE300` is the familiar rear-engine series/model name shown on the side badge. The factory/VIN model number captures the vehicle application too. For the relevant 2008–2009 IC Bus VIN chart, characters 4–5 `BW` map to `PB305` (RE school bus), and `BX` maps to `PC305` (RE commercial bus or chassis with body shell). So for this owner's school bus, use **2009 International/IC Bus RE300, model PB305**. Use `RE` for its series, `RE300` when referring to its bus series/badge, and `PB305` for the school-bus factory/VIN model number. `PC305` applies to a commercial RE build, not this school-bus build. [2008 International/Navistar VIN chart submitted to NHTSA](https://vpic.nhtsa.dot.gov/mid/home/displayfile/5c98e225-7bd7-43e9-9d54-c688e5141795), [manufacturer model chart](https://static.nhtsa.gov/nhtsa/downloads/MfrMail/01-022-N11B-10542.pdf).

Front-engine codes differ and can change across year/application charts. In the 2008 chart, `BV` maps to `PB205` FE school bus; `EY` maps to `PC085` FE commercial incomplete bus. An earlier 2005 chart lists `PC205` as an integrated FE commercial bus. Do not use a generic front-engine shorthand across model years; decode the specific VIN against its applicable manufacturer chart/build record. `PC305` is never the general code for an International 3000-series front-engine bus.

The owner has confirmed that the bus is a school bus identified as `PB305`, with an `RE300` side badge. The actual owner VIN was not found in available project notes or accessible memory records in this research pass, so we have not independently checked the VIN's positions 4–5. DieselCairn stores the owner-confirmed PB305 code as its initial model number and labels its source accurately; an actual VIN decode may later confirm or surface a mismatch. Do not substitute the separate public fixtures below for the owner's VIN.

An official NHTSA school-bus compliance report calls its test vehicle a 2009 IC Corporation RE300 school bus and records a school-bus VIN beginning `4DRBWAAN...` (VIN characters 4–5 are `BW`, the PB305 code). The report labels the vehicle model RE300, supporting the distinction between series name and school-bus model code. [NHTSA compliance test report](https://static.nhtsa.gov/odi/ctr/2009/TRTR-640256-2009-001.pdf).

VIN decoding does **not** provide the engine serial number (ESN), EFRC, ECM part/SID, ECM serial, hardware/software strategy/calibration IDs, Allison model/serial, TCM assembly/serial, TCM generation, or TCM calibration/CIN. Do not copy a seller's stock number or module part number into a serial-number field.

The manufacturer VIN chart documents broad model and engine-code classifications, not a vehicle build sheet. Even where the VIN/vPIC result yields an engine family, it must not be used to infer the ESN, exact transmission/Allison series, TCM generation, calibration, axle ratio, option codes, or installed hardware. ## MaxxForce DT diagnostic and programming workflow

Navistar bulletin IK2600282 covers model years 2007–09 MaxxForce DT/9/10. It lists the target-specific identity fields required for ECM service, including VIN, 14-digit ESN, 8-character software ID, 4-digit EFRC, rated HP, ECM module/part/SID, hardware version, software strategy, and calibration version. It includes a sample engine serial `466HM2U3057741` alongside another truck's VIN and engine report; this can be used only as a format/reference example, not as an ID for this bus. The bulletin does not provide a compatible image. [Navistar IK2600282 on NHTSA](https://static.nhtsa.gov/odi/tsbs/2025/MC-11019110-0001.pdf).

The documented procedure uses J1708 for NavKal's **Save Request** step and J1939 for programming. DieselCairn's CAN-only path is insufficient for that complete OEM workflow. Confirm the RE300's data-link connector, exact pins/active links, NavKal version/license, and supported interface before a hardware design or flash plan is approved.

Navistar's NED guide describes **Simulate Non-Connected Engine** for browsing selected-engine procedures/signals/parameters. It does not document emitting external J1939/J1708 traffic, and it is not firmware for a virtual ECU. NED/NavKal guides are public documentation; installer access requires an authorized Navistar account/product key and anonymous download attempts returned HTTP 403. [NED guide](https://msi.navistar.com/public/ned/4328482.pdf), [NavKal guide](https://msi.navistar.com/public/navkal/4328459.pdf), [Navistar software portal](https://msi.navistar.com/public/documents/0001360585.xml).

## Allison TCM calibration access

The user reports a 3000PTS transmission; its nameplate and the TCM generation still need confirmation. Allison's official DOC tool selection depends on control generation, and calibration retrieval/reprogramming is a licensed service workflow. The published reflash reference accepts a TCM serial, VIN, TCM assembly number, or transmission serial as lookup identifiers; it is not a public offline calibration blob. A VIN alone cannot choose a calibration. [Allison DOC FAQ](https://www.allisondoc.com/en/faqs/), [Allison service tools and TCM Reflash](https://www.allisontransmission.com/aftermarket-and-channel/parts-and-service/service-tools--information).

Allison's current tool matrix distinguishes DOC Premium (diagnostics for several product families), DOC Fleets (5th/6th-generation TCM support), DOC Premium + Flash (5th/6th-generation TCM flashing), and DOC Classic (older controls including Allison 4th Gen and WTEC families). Allison states its subscription supports RP1210C-compliant vehicle interfaces. The user's push-button shift selector and LED display establish an electronic selector, but do not identify the TCM generation. Capture the Allison transmission serial/assembly/model tag and TCM label/identity through an authorized read before choosing software or attempting a gear/calibration change. [Allison official diagnostic tool matrix](https://www.allisontransmission.com/aftermarket-and-channel/parts-and-service/service-tools--information/electronic-diagnostics--service-tools).

The period brochure's baseline 3000 is five-speed; it does not establish that an installed unit is merely a six-speed with sixth gear locked. Treat a sixth-gear request as an engineering/configuration question requiring exact hardware, TCM generation, shift schedule/CIN, engine torque rating, axle/tire/speed configuration, and OEM-approved calibration availability. Never frame a change as a generic “unlock.”

Independent conversion-owner, school-bus seller, and specialist accounts are collected separately in [Community and Independent Field Research](COMMUNITY_AND_INDEPENDENT_FIELD_RESEARCH.md). Those sources help identify the questions and approval path, but their successful examples are not evidence that this PB305's exact Allison unit is eligible. The cited independent cases differ in make, model, and transmission family.
